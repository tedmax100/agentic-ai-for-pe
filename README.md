## 建置

原稿為英文版 `chN.md` 與中文版 `zh/chN.md`，執行 `python3 build.py` 會自動建置出支援雙語切換的靜態網站至 `site/`（中文位於 `site/zh/`）。推送到 `main` 後，GitHub Actions 會自動建置並發佈到 GitHub Pages。
