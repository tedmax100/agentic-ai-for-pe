## 建置

原稿為中文版 `zh/chN.md` 與英文版 `chN.md`，執行 `python3 build.py` 會自動建置出支援雙語切換的靜態網站至 `site/`（中文為預設位於根目錄，英文位於 `site/en/`，舊的 `site/zh/` 路徑亦提供無縫重新導向）。推送到 `main` 後，GitHub Actions 會自動建置並發佈到 GitHub Pages。
